# Changelog — Padrino Store

Cada release de GitHub usa este archivo como cuerpo (`body`) del release.
El diálogo de actualización en la app lo parsea y muestra como lista.

**Formato:** una línea por cambio. El CI toma todo lo que hay bajo
"Próxima release" hasta "## Archivo" y lo publica como notas del release.

---

## Próxima release

- Prioridad: el enlace con formato EXFAT es el recomendado y sale primero en la lista de fuentes.
- Rendimiento: abrir la página de un juego es más ágil: los juegos relacionados se calculan una sola vez, la portada se precarga más tarde y un feed de fuentes sin cambios no se relee.
- Descargas: iniciar una descarga ya no espera detrás de las consultas de fondo del catálogo; ceden el turno y se reprograman.
